## 다음 단계로 가려면

도구의 **「다음 단계」** 메뉴에 같은 내용과 체크 목록이 있습니다. 자세한 답은 [기획서 11장](docs/01_프로젝트_기획서.md#11-2026-09-29-수강생-질문--다음-단계로-넘어가려면)에 있습니다.

1. **실제 이력으로 써 봐 주세요.** 품질불량 이력 Excel 을 「Excel·CSV 불러오기」로 열고 「열 맞추기」까지 한 뒤, 유사 불량·반복·다발·월간 현황을 써 봐 주세요. 품번·고객사처럼 밖으로 내기 어려운 값은 사본에서 바꿔도 됩니다(파일은 브라우저 밖으로 나가지 않습니다).
2. **안 맞았던 점을 적어 주세요.** 연결할 곳이 없던 열, 읽지 못한 날짜·수량, 원하는 사례가 안 나온 검색어, 기준이 맞지 않던 반복 탐지.
3. **보내 주실 것**
   - 기획서 10장 질문 10개의 답
   - 값을 가린 이력 Excel 10~20행, 또는 열 이름 목록 — 「다음 단계 → 요약 글 만들기」가 열 이름·건수·기간·불량유형 이름만 모은 글을 만들어 줍니다
   - 불량 사진: 불량유형 이름으로 폴더를 나눠 유형마다 20장 이상(가능하면 50장), 정상품 사진도. 파일 이름에 관리번호. 반출이 어려우면 유형별 장수만
   - 문서: 개선대책서·재발방지대책 3~5건(가린 것)과 형식, 검사기준서·작업표준서 등 사내 표준 목록
4. **2단계에서 만드는 것(순서)** — ① 실제 이력에 맞춰 열 맞추기·표기 사전·반복 기준 보정(**2026-09-30 반영**) → ② 대책서 Excel 에서 현상·원인·대책 뽑아 이력에 합치기 → ③ 대책서·표준 근거 질의(RAG, NotebookLM 부터) → 사진은 모이면, KPI 는 만들지 않음(2026-09-30 답)

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(Excel 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

처음 열면 데이터가 비어 있습니다.

- **「예시 데이터 불러오기」** 를 누르면 시연용 가상 이력 54건이 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다. 품번·고객사·원인·대책은 모두 지어낸 값입니다.
- 실제 파일은 **「Excel·CSV 불러오기」** → 「열 맞추기」에서 내 파일의 열을 표준 항목(발생일·품번·불량유형·불량현상·원인·대책 등)에 연결합니다. 연결은 저장되어 다음에 자동으로 맞춰집니다.
- 예시 파일: `samples/예시데이터_품질불량이력.xlsx`, `samples/예시데이터_품질불량이력.csv` — 열 이름을 일부러 다르게(P/N, 불량 구분, 조치내용 등) 적어 두어 열 맞추기를 시험할 수 있습니다.
- 데이터는 **이 브라우저에만** 저장되고 서버로 보내지 않습니다(이력은 localStorage, 사진은 IndexedDB). 보관·이동은 **「백업 내려받기」**(이력·설정·사진을 JSON 하나로) → 다른 브라우저에서 「백업 되살리기」로 합니다. 보고용은 「Excel 내보내기」·「Excel + 사진 ZIP」.
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음, 54개)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`
