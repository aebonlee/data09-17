## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-17/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(Excel 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

처음 열면 데이터가 비어 있습니다.

- **「예시 데이터 불러오기」** 를 누르면 시연용 가상 이력 54건이 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다. 품번·고객사·원인·대책은 모두 지어낸 값입니다.
- 실제 파일은 **「Excel·CSV 불러오기」** → 「열 맞추기」에서 내 파일의 열을 표준 항목(발생일·품번·불량유형·불량현상·원인·대책 등)에 연결합니다. 연결은 저장되어 다음에 자동으로 맞춰집니다.
- 예시 파일: `samples/예시데이터_품질불량이력.xlsx`, `samples/예시데이터_품질불량이력.csv` — 열 이름을 일부러 다르게(P/N, 불량 구분, 조치내용 등) 적어 두어 열 맞추기를 시험할 수 있습니다.
- 데이터는 **이 브라우저(localStorage)에만** 저장되고 서버로 보내지 않습니다. 보관·이동은 「Excel 내보내기」로 합니다.
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 이력 Excel 가져오기 | 완료 | Excel(여러 시트·여러 파일)·CSV 읽기, 머리행 자동 찾기, 열 맞추기 화면(열 이름 자동 추천), 연결 저장·재사용, 못 읽은 날짜·수량 표시, 빈 표준 양식 내려받기 |
| 품번/불량유형/원인별 관리·필터 | 완료 | 기간·품번·불량유형·원인·공정·고객사·낱말로 거르기, 유형·품번·원인·공정·고객사별 건수·수량 집계, 건 추가·고치기·삭제, Excel·CSV 내보내기 |
| 분류 표기 정리 | 완료 | 띄어쓰기·대소문자·기호만 다른 표기는 자동으로 묶음, 낱말이 다른 표기는 대표 이름을 적어 묶는 사전(불량유형·원인 분류·발생원인). 원래 이력은 그대로 두고 화면·집계·탐지·검색에만 적용 |
| 유사 불량 검색 | 완료 | 현상·품번·유형을 넣으면 겹친 낱말 수 + 같은 품번·유형 가산점 순으로 과거 이력과 당시 원인·대책·재발방지대책 표시, 겹친 낱말 강조. 가산점·표시 개수는 사용자 설정 |
| 반복·다발 불량 탐지 | 완료 | 「같은 묶음이 N일 안에 M건 이상」 규칙, 묶음 기준(품번+유형 / 유형 / 품번 / 품번+원인)과 N·M 사용자 설정, 이어진 구간 묶기, Excel 내보내기 |
| 월간 현황 | 완료 | 월별 건수·수량 막대 차트와 표, 보고할 달의 건수·수량(전월 대비)·유형별·품번별·원인별 상위 5, 그달 걸린 반복·다발, Excel 내보내기, 인쇄 화면 |
| 대책서 초안 프롬프트 생성 | 완료(반자동) | 새 불량 정보 + 유사 과거 이력(골라 빼기 가능)을 붙인 프롬프트 생성·복사 → AI 답변을 붙여넣으면 불량현상·발생원인·개선대책·재발방지대책 네 칸으로 나눔 → 검토 후 이력에 새 건으로 등록·텍스트로 받기 |
| KPI 보고서 | 다음 단계 | 불량률 등 KPI 정의·분모(생산 수량) 자료를 받은 뒤 2단계 |
| 반복·다발 알림 | 다음 단계 | 메일·메신저 알림은 2단계(Make). 지금은 화면·Excel로 확인 |
| 대책서·대응자료 문서 검색(RAG) | 다음 단계 | 2~3단계 |
| 불량 사진 기반 현상 작성·분류 | 다음 단계 | 3단계 |
| AI 자동 분류 | 다음 단계 | 3단계 |
