# data09-17 · AI 기반 품질불량 자동 분석 시스템

품질불량 이력을 품번·불량유형·원인별로 관리하고 유사 불량 검색·반복 불량 탐지·월간 현황과 대책서 초안 작성을 지원하는 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 안지혁 |
| 과정 | 현장 데이터 수집·디지털화 전문가과정 1차수 (2026) |
| 진행 단계 | 1단계 — 프로젝트 기획서 등록 (2026-09-28) |
| 다음 개발 | 품질불량 이력 Excel을 열 매핑으로 가져와 품번·유형·원인별 필터, 키워드 유사 불량 검색, 반복·다발 탐지(기준값 사용자 설정), 월간 현황 표·차트, 과거 이력을 붙인 대책서 초안 프롬프트 생성까지 하는 브라우저 도구(사진 분류·RAG는 2~3단계) |
